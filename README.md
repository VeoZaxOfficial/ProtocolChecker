# ProtocolChecker

ProtocolChecker is a plugin for VeoZaxAPI that checks player protocol versions and prevents unsupported clients from joining the server.

## 🔧 Requirements
- VeoZaxAPI (custom fork)

## ✨ Features
- Logs player protocol on login
- Blocks unsupported versions
- Lightweight and simple

## 📦 Installation
1. Download this plugin from here: https://www.mediafire.com/file/3mdj7gzpyl7rw74/ProtocolChecker_v1.0.0.phar/file
2. Place the plugin in your /plugins folder
3. Restart your server
